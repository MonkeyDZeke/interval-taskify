# To Do - Plasma Widget

A task manager for tracking relative urgency of recurring tasks balanced with cognitive capacity, built as a widget for KDE 6, forked from https://github.com/miradozk/todo-by-thepiou

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Plasma](https://img.shields.io/badge/Plasma-6.0+-blue.svg)

## Requirements

- KDE Plasma 6.0 or higher
- Qt 6
- kpackagetool6
